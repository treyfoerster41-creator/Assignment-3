# Still - Assignment 3

Still is a proposed local coursework prototype for practicing short meditation skills. It is a design project at the Assignment 3.1 checkpoint; it is not a working application or a mental health support service.

The current design supports two short practices: paced breathing (inhale for four, exhale for six) and 5-4-3-2-1 sensory grounding. Both are optional, fixed course skills. The intended experience requires no writing, allows the user to pause or leave, and keeps crisis-support information visible independently of model availability.

## Current state

- The study findings and their design implications are recorded in [the design note](docs/application-design.md).

## Safety and data

Use fictional scenarios only. Do not offer, deploy, link, or recommend this coursework prototype as support for a person in distress. The project makes no diagnosis, therapy, clinical-effectiveness, or human-monitoring claims. Never include real identities, private conversations, API keys, or `.env` contents in repository files or evidence.
